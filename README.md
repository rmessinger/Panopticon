# Panopticon

Panopticon is an open-source C# simulation framework built on a reimplementation of the SAGE RTS engine, focused initially on Command & Conquer: Generals and Zero Hour.

Panopticon originated from [OpenSAGE](https://github.com/OpenSAGE/OpenSAGE).

The repository includes simulation and rendering, game-data parsers, external asset importers, headless benchmarks, a visual TestHarness, and the ReplaySketch inspection tool. Development targets scalability, extensible simulation techniques, and large-scale battle experiments across Windows, macOS, and Linux.

Work in progress. Original game content requires a legally acquired installation. Panopticon is not affiliated with Electronic Arts.
