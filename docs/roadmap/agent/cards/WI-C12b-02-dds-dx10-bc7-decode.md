## Goal

Imported materials can reference DDS textures: `DdsFile` reads the `DX10` extended header, `DdsBlockDecoder` decodes BC7, and `ImportedImageDecoder` decodes DDS base mips to RGBA for imported sources.

## Context to read (and only this)

- `docs/roadmap/deep-dives/c12-total-war-shogun2-models.md` sections 4, 9 (implementation decisions), and the class diagram.
- `src/Panopticon.Simulation/Data/Dds/DdsFile.cs`, `DdsImageFormat.cs`, `DdsBlockDecoder.cs`.
- `src/Panopticon.Simulation/Content/Loaders/ImportedImageDecoder.cs`, `ImportedTextureMaterializer.cs`.
- If `WI-C10a-03` is `Done`, its DDT branch in `ImportedImageDecoder` (follow the same shape).

## Steps

1. Read the `DX10` FourCC and its 20-byte extended header in `DdsFile`, mapping DXGI BC1, BC3, and BC7 (UNORM and SRGB) to `DdsImageFormat`; add `Bc7` and an sRGB flag. Unknown DXGI formats throw with the format number.
2. Add BC7 decoding (all 8 modes) to `DdsBlockDecoder.DecodeBaseMip`.
3. Replace the DDS rejection in `ImportedImageDecoder` with a base-mip decode through `DdsFile` and `DdsBlockDecoder`; mips are regenerated by the materializer. Keep the W3D DDS GPU path untouched.
4. Propagate the sRGB flag so base-colour maps are not double-converted, using the existing `SrgbColour` key in `ImportedTextureMaterializer`.
5. Add tests: BC7 mode vectors against known RGBA output, a synthetic `DX10` header file per mapped format, and the imported-source DDS decode.
6. Add an Interactive test that decodes the proof head part `texture_basecolor`, `texture_mra`, and `texture_normal` with their recorded formats.
