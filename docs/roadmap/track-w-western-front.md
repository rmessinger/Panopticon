# Track W: Western Front Simulation

> Part of the [Large-Scale RTS Roadmap](README.md). This track turns the
> [Western Front goal charter](deep-dives/western-front-scale-simulation.md) into staged
> demonstrations: a multi-layer First World War simulation built as a domain on the shared
> `GameObject`/module runtime through the [A4-1 seam](deep-dives/a4-simulation-domain-model.md).
>
> Architecture context: see [`agent/current-state.md`](agent/current-state.md).
>
> Audience: human overview of the Western Front track.

## Track ordering rationale

The charter's twelve decision gates are settled (see the
[Western Front decision gates](open-questions.md)). Runs are offline and detail-first: the
all-tactical run is the primary product, and aggregate resolution covers rear areas and quiet
sectors with measured error. W0 fixes state, keys, clocks, and conservation
on synthetic data before any gameplay system exists. W1 and W2 prove the aggregate model and
fidelity transitions on that synthetic fixture. W3-W6 then compose them with geospatial terrain,
experiment sweeps, distribution, and long runs, each gated on the owning Track A/B phase.

## Phases

> The Milestone column states the demonstrable outcome that marks each phase done. Granular steps
> live in [`implementation-checklist.md`](implementation-checklist.md).

| Phase | Goal | Milestone | Status | Depends on |
|---|---|---|---|---|
| W0. Charter fixture | Synthetic geography and formations define stable keys, layer boundaries, the state vector with units and owners, clock modes, and conservation rules through the [A4-4 domain state projection](deep-dives/a4-4-domain-state-projection.md). | A fixture run serializes theater, operational, aggregate, and tactical records; recording reconstructs each layer at selected frames; every quantity has an owner and unit; conservation residuals are empty. | Not started | A4-1, A4-4 |
| W1. Aggregate sector simulation | Connected sectors with formation movement, capacitated supply flow, delayed orders over communication links, echelon-local information, and stochastic Lanchester combat, all at operational and campaign cadence. | A seven-day synthetic offensive conserves every family exactly, reports order and logistics metrics, reconstructs from the artifact, and repeats per seed for both combat variants. | Not started | W0, A2 |
| W2. Fidelity promotion and reconciliation | Promote contested regions into one `GameObject` per soldier on the Track P runtime, run the engagement until the activation policy demotes, and reconcile exactly behind a pluggable activation policy. | Formation identity and holdings survive promote, engage, demote with no loss or duplication; each transition is recorded; a whole-sector all-tactical reference measures the aggregate model's error. | Not started | W1, A4-3 |
| W3. Geospatial sector | Run W1/W2 on the Somme 1916 sector generated by B4b, with regions, cells, and links derived from source features. | W1/W2 evidence repeats on the generated sector; keys map to source features; control-point tolerances hold. | Not started | W2, B4b |
| W4. Command and logistics experiment | Sweep order latency, reconnaissance, link capacity, activation policy, and combat variant. | Distributions with confidence intervals per cell, sensitivity ranking, and a passing information audit. | Not started | W2, A5 |
| W5. Distributed regional simulation | Shard the W2 scenario into strips perpendicular to the front, for memory and capacity, and compare with the single-process run. | Ownership and conservation invariants hold across shards; cross-boundary effects resolve exactly once; outcome distributions compare with the single-process run. | Not started | W2, B6 |
| W6. Long-run campaign experiment | A parameterized July-November 1916 campaign with save/load (domain-state snapshot plus host save), optional historical order of battle, and replay scrubbing. | Bounded memory and artifact size, measured wall-clock scaling, reconstruction latency, provenance, and declared error per fidelity policy. | Not started | W3, W4, W5 |

## Cross-track dependencies

- A4-4 (Track A) adds the reconstructable multi-layer state projection W0 requires; it is useful
  to any domain and lands in Track A.
- W2 is the first formation-level instance of B7-4 group aggregation and does not wait for B7;
  B7-4 generalizes its contracts later.
- W2 reuses Track P combat and the A4-3 squad hierarchy for tactical actuation; Western Front
  content replaces placeholder Generals definitions through Track D when available.
- W3 consumes B4b's generated package and B4a chunking; W5 consumes B6 partitioning; W4 and W6
  consume A5 sweeps and replay.
- Track F deformation is not required through W6; region terrain levels summarize trench, wire,
  and crater state. F1/F3 can replace the summaries in active regions later.
