# Track C: External Models & Animations

> Part of the [Large-Scale RTS Roadmap](README.md). This track adds unit models and animations
> authored outside the Westwood `.w3d` ecosystem. The design begins with a format-agnostic import
> abstraction before any concrete format is implemented.
>
> Architecture context: see [`agent/current-state.md`](agent/current-state.md).
>
> Audience: human overview of the external-assets track.

> The Milestone column states the demonstrable outcome that marks each phase done. Granular steps live in
> [`implementation-checklist.md`](implementation-checklist.md).

## Cross-track dependencies

- C1 and A3 both touch the presentation seam, so the import abstraction should feed the same runtime `Model`/`ModelInstance` types that [B5](track-b-scale.md) expects.
- B5 should account for Track C models so instancing is not W3D-specific.
- C4a turns the [Empire Earth II Gamebryo survey](deep-dives/ee2-gamebryo-model-storage.md)
  into a static second-format proof of the C1 seam. It does not replace C4 or add EE2 as a
  supported game. C4b through C4i extend that proof with textures, rigid, skinned, property,
  scale, and morph animation, particle effects, and legacy KF vintages under the same boundary.
- C7a through C7c add StarCraft II as a third external format through the same operator-supplied,
  no-committed-assets boundary. C7c widens the C4f scale work to per-axis scale and adds absolute
  local-transform clips, so it follows C4f.
- C8 extends the native W3D path for BFME, BFME2, and RotWK art instead of adding an importer. Its
  BFME2 ships are the reference hulls for [Track E](track-e-naval-warfare.md). BFME gameplay INI
  stays in [Track D](track-d-gameplay-expansion.md) D3.
- C9 through C11 add Total War: THREE KINGDOMS, Age of Empires III: DE, and Rise of Legends under
  the C7 boundary. C9 composite soldiers and LODs feed [B5](track-b-scale.md) and
  [Track M](track-m-mass-battle.md); C9d stops at composition, and rendering at scale stays B5.
- C12 adds Total War: SHOGUN 2 Complete Edition under the same boundary. It shares the C9 pack
  project and the C10a LZ4 decoder, whichever lands first, but no model or clip reader, and feeds
  B5 and Track M the same way as C9.
